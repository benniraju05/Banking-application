# Python GUI Banking System 💰

A desktop banking application developed in Python using the Tkinter library. This project demonstrates strong proficiency in **Object-Oriented Programming (OOP)** by completely separating the core business logic (Account and Bank classes) from the graphical user interface (GUI).



## ✨ Key Features

* **OOP Architecture:** Clear, modular separation of data management (`Account` class) and account collection (`Bank` class).
* **Account Management:** Allows users to **Create New Accounts** with essential personal and balance details.
* **Transaction Processing:** Supports **Deposit** and **Withdrawal** operations with input validation.
* **Real-time Feedback:** Uses `tkinter.messagebox` to provide success messages and error handling (e.g., non-positive amounts, insufficient funds, account number conflicts).
* **Transaction History:** Displays a detailed, up-to-date transaction history for any loaded account.
* **Multi-Screen Navigation:** Seamless navigation between the Welcome, Account Creation, and Transaction screens.

## 🛠️ Technology Stack

* **Language:** Python 3.x
* **GUI Library:** `tkinter`
* **Data Structures:** Class-based objects and dictionaries (for storing accounts).
